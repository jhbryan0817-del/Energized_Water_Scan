# Rev G electrical baseline

Historical files retained to document the PCB represented by the existing Rev G mechanical model. Use [Rev H](../RevH/README.md) for current electronics, BOM, wiring and validation. No Rev G CAD or 3D file was changed in the Rev H iteration.

Rev G used one multiplexed ADS1115 for two isolated ranges, unconnected controller diagnostic inputs, and unprotected battery polarity. Its reports apply only to that saved revision. The old manufacturing files are not a current fabrication release. Detailed revision history remains in Git.
