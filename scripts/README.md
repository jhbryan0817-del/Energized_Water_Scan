# Script scope

These retained scripts belong to earlier mechanical and four-probe development revisions. They are not Rev H acquisition firmware or current acceptance tests. In particular, the four-probe gradient/pose assumptions do not apply to the present two-electrode USV. Do not run old Fusion export or mutation scripts against the live assembly without a separate revision-specific review.

Current electronics sources and validation are in `../pcb/RevH/`; current project status and outstanding work are in the root README and `../docs/`. No scripts in this directory were changed in the PCB iteration.
